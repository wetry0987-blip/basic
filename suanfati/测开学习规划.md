### 第一阶段：打地基（2026.8 - 2026.12）

这个阶段的核心策略是**让408备考和Java学习互相喂养**，而不是两条独立的线。

**408与Java的交叉点（一鱼两吃）：**

- 数据结构（408）→ Java集合框架源码（ArrayList/HashMap/TreeMap），学完408的数据结构直接看Java对应实现
- 操作系统（408）→ Java并发编程基础（线程、锁、进程模型对应），进程/线程调度概念直接复用
- 计算机网络（408）→ HTTP协议、TCP/IP，这些是后续做接口开发和理解Agent调用链的基础

**每周安排（工作日）：**

| 时间段 | 内容 | 时长 |
|--------|------|------|
| 午休 | LeetCode简单题1道（用Java写） | 30min |
| 晚上第一段 | 英语（考研） | 1h |
| 晚上第二段 | 408专业课 | 1.5h |
| 晚上第三段 | Java基础 / 工作中自动化脚本 | 45min |

**每周安排（周末）：**

| 时间段 | 内容 | 时长 |
|--------|------|------|
| 上午 | 408数学/专业课 | 3h |
| 下午 | Java学习 + 编码练习 | 3h |
| 晚上 | 休息/自由安排 | - |

**Java学习路线（从当前位置开始，约7周）**

> 你的起点：语法基础✅ | 面向对象✅ | 集合框架（学了但没学完）| 异常处理（学了）| IO | 多线程❌ | Lambda/Stream❌ | 设计模式❌
>
> 策略：先花3天快速摸底+补完集合和异常，然后从IO往下学。

### 第二阶段：框架 + 项目 + Agent入门（2027.1 - 2027.4）

考研结束后进入全力冲刺期。

**1月：Spring Boot 快速上手**

- Spring Boot核心：IoC、AOP、自动配置原理
- 写RESTful API（CRUD接口）
- MyBatis-Plus操作数据库
- Redis基础用法（缓存、分布式锁）
- 推荐：B站 黑马程序员Spring Boot教程

**2月：第一个完整项目 —— 结算测试数据平台**

结合你熟悉的结算业务场景，做一个真实可用的工具：

项目名（暂定）：**结算链路Mock平台**
- 功能：模拟结算系统上下游接口，支持自定义规则配置、请求录制回放、异常场景注入
- 技术栈：Spring Boot + MySQL + Redis + MyBatis-Plus
- 核心模块：
  - 接口管理：配置Mock接口和返回规则
  - 数据工厂：按业务规则批量生成测试数据
  - 回放引擎：录制真实请求，按规则回放
  - 简单Web界面（用Thymeleaf或前后端分离都行）

这个项目的好处：面试时能讲清楚业务背景（你天天在测的结算链路），技术方案也不复杂，但能展示你的开发能力。

**3月：Agent入门**

- LLM基础：理解Token、Prompt、Temperature等核心概念
- API调用：通义千问/OpenAI API，学会Function Calling机制
- RAG入门：向量数据库（Milvus或DashVector）+ 文档切分 + 检索增强生成
- 框架入门：LangChain（Python）或Spring AI（Java），选一个深入

**4月：Agent + 测试的结合点**

开始构思第二个项目，把Agent能力引入测试领域：

项目方向（选一个）：
- **智能用例生成器**：输入接口文档（Swagger/OpenAPI），LLM自动生成测试用例（含边界值、异常场景）
- **缺陷分析报告Agent**：输入日志+报错信息，Agent自动分析根因并生成报告
- **结算规则验证Agent**：输入业务规则描述，Agent自动生成验证脚本并执行

**阶段里程碑：**
- [ ] Spring Boot项目能独立从零搭建并部署
- [ ] 结算Mock平台项目完成，部署到服务器（或本地可演示）
- [ ] 能用LLM API实现Function Calling
- [ ] RAG链路跑通（文档→向量化→检索→生成）
- [ ] GitHub上有2个可展示的项目

### 关于考研和转行的关系

你12月考研，不管结果如何，对转行都有帮助：
- 考上了：读研期间有完整时间系统提升技术，研究生学历也是加分项
- 没考上：408的知识不会浪费，Java基础已经打好了，直接进第二阶段

所以考研和转行准备不矛盾，第一阶段的核心就是让两者重叠。
